# Tarefou

Aplicação web desenvolvida para ajudar na organização e no gerenciamento de tarefas do dia a dia.

## Sobre o projeto

O **Tarefou** é um gerenciador de tarefas que permite cadastrar, organizar e acompanhar atividades de forma simples e prática.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de colocar em prática os conhecimentos adquiridos durante meus estudos em Ciência da Computação.

Durante o desenvolvimento, busquei criar uma interface agradável, organizada e fácil de utilizar, além de trabalhar com diferentes funcionalidades do JavaScript.

## Funcionalidades

- Adicionar, editar e excluir tarefas.
- Marcar tarefas como concluídas.
- Organizar atividades por categorias.
- Definir datas e horários para as tarefas.
- Pesquisar e filtrar tarefas.
- Visualizar tarefas em um calendário.
- Acompanhar a quantidade de tarefas pendentes e concluídas.
- Salvar as tarefas no navegador utilizando LocalStorage.
- Utilizar a aplicação em computadores e dispositivos móveis.

## Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e responsividade.
- **JavaScript** — funcionalidades e interatividade.
- **LocalStorage** — armazenamento das tarefas no navegador.

## Como utilizar

1. Baixe os arquivos do projeto ou clone o repositório.
2. Abra a pasta do Tarefou.
3. Execute o arquivo `index.html` no navegador.

A aplicação funciona diretamente no navegador, sem necessidade de instalação.
